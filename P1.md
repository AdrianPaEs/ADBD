**a. Crear dos usuarios: `admin_biblio` con permisos de administrador sobre la base de datos y `usuario_biblio` con permisos solo de lectura.**
```sql
postgres=# CREATE USER admin_biblio WITH PASSWORD 'admin_biblio' SUPERUSER;
CREATE ROLE
postgres=# CREATE USER usuario_biblio WITH PASSWORD 'usuario_biblio';

```
